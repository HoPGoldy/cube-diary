# 写入日记

将 `<service>` 替换为已配置的服务名，通常是 `cube-diary`。

## 确定日期

- 用户指定日期时，将其转换为 `YYYYMMDD`。
- 用户说“今天”或没有指定日期时，使用系统本地日期，不使用示例中的固定日期。
- 日期含义不明确时先询问用户。

## 写入步骤

1. 读取目标日期已有内容：

   ```bash
   oac <service> post-api-diary-get-detail \
     --body '{"dateStr":"<YYYYMMDD>"}'
   ```

2. 根据结果处理：
   - 没有已有内容：直接准备新内容。
   - 已有内容且用户要求追加：保留原文，在末尾追加新内容。
   - 已有内容且用户明确要求替换：使用新内容替换。
   - 已有内容但用户未说明：询问追加还是替换，不得默认覆盖。

3. 写入完整的最终内容：

   ```bash
   oac <service> post-api-diary-update --body '{
     "dateStr": "<YYYYMMDD>",
     "content": "<最终完整内容>",
     "color": null
   }'
   ```

`dateStr` 是必填字段；`content` 和 `color` 按用户要求提供。构造 JSON 时正确转义换行、引号和反斜杠。

## 写入后

向用户说明写入日期和执行的是新建、追加还是替换。不要在用户未要求时复述整篇私人日记。
